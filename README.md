# Stacked Area Charts with Python and Matplotlib

Python/Matplotlib scripts drawing stacked area charts of morphometric variables, demonstrated on Mariana Trench data. Reusable scientific-plotting example.

## Scripts

- `stacked_area_chart_a.py`
- `stacked_area_chart_b.py`

## Data

- `Tab-Morph.csv`

## Requirements

Python 3 with `matplotlib`, `numpy`, `pandas`, `seaborn`.

```
pip install matplotlib numpy pandas seaborn
```
